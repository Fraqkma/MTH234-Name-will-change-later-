Three objectives, one design matrix

OLS, Ridge, and Lasso

Here X is the design matrix, y contains observed values, and β contains the intercept and other coefficients.

OLS

minβ ‖y − Xβ‖22

Choose coefficients that make the squared prediction errors as small as possible.

Ridge

minβ ‖y − Xβ‖22 + λ‖βnonintercept‖22

Discourage large non-intercept coefficients with a squared penalty.

Lasso

minβ (1 / (2n))‖y − Xβ‖22 + α‖βnonintercept‖1

Discourage large non-intercept coefficients and allow some to become exactly zero.

The intercept is unpenalized in both methods. Ridge λ and Lasso α use different penalty conventions and are not directly comparable numbers.

Show derivation

For Ridge, set the gradient to zero: (XTX + λP)β = XTy, with P = diag(0, 1, …, 1). The zero leaves the intercept unpenalized.

For a non-intercept Lasso coordinate j, let rj = y − Xβ + Xjβj, ρj = XjTrj/n, and zj = ‖Xj‖22/n. Then βj ← S(ρj, α)/zj, where S(t, α) = sign(t) max(|t| − α, 0). Update the intercept without thresholding.

Interactive 3D loss

Rotate the loss surface

The full two-parameter model has an intercept and a slope. The surface height is SSE + lambda * slope^2; the intercept is free.

Loading the objective.

With a design matrix A, least squares chooses coefficients w so that Aw is as close as possible to the observed vector y.

Least-squares objective minw ‖y − Aw‖22

The residual is perpendicular to every column of A, giving the normal equations:

ATAw = ATy

For computation, solve with QR or an SVD-based least-squares routine. Forming an explicit inverse is unnecessary and can amplify numerical error.

03

Ridge regression lab

Constrain the coefficients, not the evidence

Ridge adds a cost for large non-intercept coefficients. The λ control changes that cost while the OLS and Ridge fits use the same training data and the same training-fitted feature scaling.

Unpenalized intercept ‖y − Aw‖22 + λ ∑j>0 wj2

Increasing λ shrinks the polynomial terms and can trade variance for bias. Too much regularization can underfit; Ridge is not guaranteed to improve validation error.
